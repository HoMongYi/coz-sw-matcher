# 검수 정책

- 판촉/유통사/후속모델과 현재 모델을 분리한다.
  중첩 괄호를 통째로 삭제하지 않는다.
- SE+의 +는 모델 일부다.
  독립적인 결합 기호만 구성품 구분자로 사용한다.
- 색상/스위치/벌크/한글판을 별도 속성으로 기록하더라도 지원 차이가 없다고 단정하지 않는다.
- GPU driver 제공사와 보드 제조사 firmware를 구분한다.
- 공식 다운로드/지원 목적 및 정확 모델 근거가 없으면 보류한다.
  JS/CAPTCHA/차단을 우회하지 않는다.
- Registry의 과거 검수는 새 실접속 증거가 아니다.
  verified_at을 임의 생성하지 않는다.
- GitHub Actions와 연결된 시스템의 허용되지 않은 변경을 사용하지 않는다.
