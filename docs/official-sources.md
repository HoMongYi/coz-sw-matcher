# 공식 출처

공식 도메인 목록은 data/public/vendors에 있으며 provenance를 추적한다. 공식성은 모델/리비전·SW 유형 적합성과 별개다. 소개 페이지는 다운로드 근거가 없으면 추천하지 않는다.

GPU driver는 NVIDIA/AMD/Intel 제공사를 구분하며 firmware는 보드 제조사를 따른다. ATK의 한국어 HUB는 https://www.atk.store/ko-kr/pages/atk-hub 이지만 정확 모델 지원은 별도로 확인한다. 유통사 도메인은 확인된 제조사 위임 근거 없이 허용하지 않는다.

네트워크 제한과 차단 시 보류 정책은 [보안](../SECURITY.md)을 참조한다.
