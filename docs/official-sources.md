# 공식 출처

공식 도메인 목록은 `data/public/vendors`에 있으며 각 레코드의 `provenance`에 출처를 기록한다.
공식 도메인인지와 해당 모델·리비전·SW 유형에 맞는지는 각각 확인해야 한다.
상품 소개 페이지는 다운로드 근거가 없으면 추천하지 않는다.

GPU 드라이버는 NVIDIA·AMD·Intel 등 실제 제공사를 구분한다.
보드 펌웨어는 보드 제조사의 정확 모델 근거를 확인한다.
ATK 한국어 HUB의 공개 주소는 <https://www.atk.store/ko-kr/pages/atk-hub>이지만, 개별 모델의 지원 여부는 별도로 확인한다.
유통사 도메인은 제조사의 위임 근거를 확인하기 전까지 허용하지 않는다.

네트워크 제한과 차단 시 보류 정책은 [보안 문서](../SECURITY.md)를 따른다.
