# 처리 흐름

1. 원문 보존과 상품명 구조 파싱.
2. 제조사·유통사·정확 모델·SW 제공사 분리. 결합상품은 대상 선택.
3. 기존 후보 또는 로컬 Registry 수신. 외부 후보가 없을 때만 선택적 검색.
4. 공식 도메인·모델·페이지 용도·독립 근거 검사.
5. 0~5개 룰 순위와 선택적 Luna 재정렬.
6. 담당자 검수와 사내 승인 계약 처리.

접속 차단, Provider 실패, 모델 불명확은 needs_review다. 실제 승인 저장은 이 프로젝트 범위 밖이며 [전산팀 계약](integration.md)을 따른다.
