# Coz SW Matcher 검증 범위

Coz SW Matcher의 로컬 검증과 운영 환경에서 추가 확인할 항목을 구분한다.

## 로컬 검증

- Node.js 22 이상이 필요하다. 이번 유지보수 검사는 Node.js 24.13.1에서 실행했다.
- 상품명 golden 6개, 중첩 괄호, SE+, D4/D5·리비전, 유통사 변경, 후속모델, 결합상품을 검사한다.
- 후보 0~5개, 중복 검색 방지, 공식성·정확 모델·요청 SW 유형·페이지 목적, Provider 장애·취소·잘못된 응답을 검사한다.
- 신규 API는 자동 승인하지 않는다.
  승인 계약은 저장·인증 없이 형식만 검증한다.
- CLI, 루프백 HTTP, 공식 MCP SDK의 실제 stdio, Skill wrapper를 검증한다.
- 공개 파일·소스/Skill/Plugin/npm 패키지의 해시·경로·라이선스·비공개 데이터 제외를 검사한다.

문서·영상 개편 당시 로컬 회귀 테스트 180개를 통과했다.
README 이미지의 패키지 포함 여부와 잘못된 형식·크기 제한 검사를 포함한다.
golden 사례 통과를 전체 상품 인식률로 설명하지 않는다.
릴리스 빌드와 독립적인 패키지 검사는 배포 전에 로컬에서 다시 실행한다.

## 데이터 평가

검수 CSV와 상세 결과는 공개하지 않는다.
평가에서는 동일 URL·모델 패밀리·SW 생태계의 연결 그룹을 분리하고, 확인 필요 항목에 가짜 정답을 만들지 않는다.

기존에 온라인 검색 없이 미등록 URL을 평가한 오프라인 holdout의 Top-5 포함률은 0%였다.
이는 미등록 URL의 오프라인 조회 범위를 나타내며 온라인 검색 정확도를 측정한 결과가 아니다.

담당자 1순위 승인율·오모델률·실제 검수 시간은 해당 레이블과 이력이 없으므로 수치화하지 않는다.

## 추가 확인

실제 API 모델 ID 검증과 유료 Rule+Luna 비교는 사용자 요청으로 보류했다.
초기 ATK·NVIDIA 단일 페이지 검사에서는 정확 모델 근거가 부족해 needs_review로 반환했다.
현재 검증은 아래의 지원 관계 개선 결과를 따른다.

실서비스 정확도, OS·펌웨어 호환성, 선택 결과 저장·인증 연동, Agent-host 설치 UI는 추가 확인 대상이다.
[연동 계약](../docs/integration.md)을 따른다.

## 지원 관계 개선 검증 — 2026-10-29

유지보수 기준 커밋은 `3ea0791343276b93a67f2f79e2e6108db00a2c76`이다.
기존 180개 테스트를 이번 작업 시작 시 다시 실행해 모두 통과한 뒤 반례를 추가했다.
새 반례에서는 혼합 괄호의 정보 유실과 미지원 페이지 오인 등이 수정 전 실패하고 수정 후 통과하는지 확인했다.

최종 로컬 실행은 `npm test` 240개 통과(기존 180개와 추가 60개, 실패·스킵 0),
`npm run lint` JS 61개, `npm run validate` 공개 파일 170개에서 알려진 비밀 패턴 0건이었다.
문서 검사에서는 Markdown 25개, 상대 링크 61개, JSON 코드 블록 4개를 확인했다.
Mermaid 2개는 원본 구조만 검토했고 이번 작업에서 화면 렌더링은 다시 실행하지 않았다.

공통 앱·웹앱, 한국어 정렬, 지역 드라이버, 구성품별 판단, Luna 응답 계약, CSV 원본 보존을 검사한다.
합성 HTML과 합성 CPU 없음 조건을 실제 제조사 검증 결과로 계산하지 않는다.
Skill 지침도 같은 사례와 수동으로 대조했으며 실제 모델이 Skill을 수행하는 성능을 측정한 것은 아니다.

유료 검색·모델 없이 공개 사례 9개를 순차 실접속했다.
NVIDIA App, 펀키스 F87 Pro, Corsair iCUE, Samsung SL-C4030ND 허브,
Canon GX6092→GX6070 허브, HARPE MINI CORE→Gear Link의 6개에서 모델 지원과 SW 대상을 확인했다.
모든 결과는 `approved=false`이며 사람이 최종 주소를 선택해야 한다.

ATK는 브라우저에서 정확 모델의 HUB 지원을 확인했지만 정적 검증에서 실행 도구까지 확인하지 못했다.
COX 자료실에서는 정확 모델 자료가 확인되지 않았고 MSI는 403이었다.
이 3개는 `needs_review`로 남았다.
자료가 비었거나 차단된 것을 SW 없음으로 바꾸지 않았다.

Canon은 양쪽 패키지의 파일명·버전·게시일과 공통 설명서를 확인했다.
바이너리 해시 비교, 설치, PS3/FAX 기능, 펌웨어 호환은 확인하지 않았다.
전체 모델 범위와 [제조사별 미확인 사항](../docs/support-evidence.md)을 구분해 읽어야 한다.
실접속 9개의 결과를 전체 추천 정확도나 학습·평가 성능으로 설명하지 않는다.

최신 검수 CSV의 실데이터 재평가와 유료 Rule+Luna 비교는 이번 작업에서 실행하지 않았다.
공개 게시, Release 변경, 운영 연동, 장치 설정·펌웨어 적용도 실행하지 않았다.

## v0.2.0 배포 검증 — 2026-10-31

버전 표기를 정리한 배포 트리에서 전체 테스트 240개를 다시 통과했다.
실패·스킵은 0개이며 lint JS 62개, 공개 파일 172개 검사에서 알려진 비밀 패턴도 0건이었다.
Markdown 26개, 상대 링크 65개, JSON 코드 블록 4개를 확인했다.
Registry의 버전도 package.json과 같은 0.2.0으로 생성했다.

이 검사는 2026-10-29의 제조사 페이지 확인을 새 실접속 결과로 갱신하지 않는다.
유료 모델·검색 호출이나 실제 설치·운영 저장 연동은 추가로 실행하지 않았다.
