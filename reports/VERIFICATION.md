# v0.1.0 검증 범위

Coz SW Matcher의 로컬 검증과 운영 환경에서 추가 확인할 항목을 구분한다.

## 로컬 검증

- Node.js 22에서 npm test, npm run lint, npm run validate를 실행한다.
- 상품명 golden 6개, 중첩 괄호, SE+, D4/D5·리비전, 유통사 변경, 후속모델, 결합상품을 검사한다.
- 후보 0~5개, 중복 검색 방지, 공식성·정확 모델·요청 SW 유형·페이지 목적, Provider 장애·취소·잘못된 응답을 검사한다.
- 신규 API는 자동 승인하지 않는다.
  승인 계약은 저장·인증 없이 형식만 검증한다.
- CLI, 루프백 HTTP, 공식 MCP SDK의 실제 stdio, Skill wrapper를 검증한다.
- 공개 파일·소스/Skill/Plugin/npm 패키지의 해시·경로·라이선스·비공개 데이터 제외를 검사한다.

문서·영상 개편 후 로컬 회귀 테스트는 180개를 통과했다.
README 이미지의 패키지 포함 여부와 잘못된 형식·크기 제한 검사를 포함한다.
golden 사례 통과를 전체 상품 인식률로 설명하지 않는다.
릴리스 빌드와 독립적인 패키지 검사는 배포 전에 로컬에서 다시 실행한다.

## 데이터 평가

검수 CSV와 상세 결과는 공개하지 않는다.
평가에서는 동일 URL·모델 패밀리·SW 생태계의 연결 그룹을 분리하고, 확인 필요 항목에 가짜 정답을 만들지 않는다.

온라인 검색 없이 미등록 URL을 평가한 오프라인 holdout의 Top-5 포함률은 0%였다.
이는 미등록 URL의 오프라인 조회 범위를 나타내며 온라인 검색 정확도를 측정한 결과가 아니다.

담당자 1순위 승인율·오모델률·실제 검수 시간은 해당 레이블과 이력이 없으므로 수치화하지 않는다.

## 추가 확인

실제 API 모델 ID 검증과 유료 Rule+Luna 비교는 사용자 요청으로 보류했다.
독립적인 공개 ATK·NVIDIA 페이지 접속에서는 현재 HTML만으로 정확 모델 지원을 입증하지 못해 needs_review로 반환했다.

실서비스 정확도, OS·펌웨어 호환성, 선택 결과 저장·인증 연동, Agent-host 설치 UI는 추가 확인 대상이다.
[연동 계약](../docs/integration.md)을 따른다.
